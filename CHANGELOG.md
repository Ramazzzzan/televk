# Изменения

## 0.1.2 — 2026-10-05

Исправления первого пилота:

- успешная отправка Telegram → VK больше не создаёт отдельное сообщение «✓ VK подтвердил приём…»; бот ставит реакцию ⚡ на исходное Telegram-сообщение;
- предупреждение «Тема не привязана к VK» показывается один раз на конкретный topic, а не после каждого сообщения;
- live-сообщения VK с неполным Long Poll payload для фото/документа дочитываются через `messages.getById`/`messages.getByConversationMessageId` до постановки медиа в очередь. Это устраняет случай, когда media-only сообщение отображалось в Telegram только заголовком.

## Pilot hardening - 2026-10-05

Первый реальный пилот подтвердил Telegram/VK preflight, чтение личных диалогов VK, запись теста в «Избранное», запуск systemd и доставку новых текстовых сообщений VK → Telegram через SOCKS-прокси.

README дополнен community-путём получения VK user token через `BigDrugs/vk-notify`. `init` и `check` теперь отбрасывают `none`/placeholder вместо VK-токена и явно некорректный Telegram Bot token (например, с лишним `:` или префиксом `bot`). Добавлены регрессионные CLI-тесты.

## 0.1.1 — 2026-10-04

Переведена установка на GitHub-first/offline-модель: зависимости скачиваются на ПК в `wheelhouse/`, сверяются с закреплённым SHA-256 release-манифестом, коммитятся в репозиторий и на HTPC устанавливаются через `pip --no-index`. Добавлены PowerShell/bash-скрипты подготовки wheelhouse, GitHub Actions тест и безопасный `install.sh --resume` для прерванной первой установки 0.1.0.

`/updates` больше не обращается к PyPI: Python-зависимости проверяются по GitHub tags, VK schema/curl/systemd — через GitHub, локальные Python/SQLite только отображаются. Исправлена гонка штатной остановки, при которой worker мог завершиться на один цикл раньше stop-task и ошибочно считаться упавшим.

Все 89 локальных тестов проходят; после исправления гонки полный набор дополнительно выполнен пять раз подряд.

## 0.1.0 — 2026-10-04

Первая отдельная реализация TeleVK. Текст, фото и документы в обе стороны, темы, ответы, явное прочтение, полный доступный архив одного чата, уведомления о неподдерживаемых типах, односторонний mute и проверки версий.

Добавлены постоянные очереди SQLite, атомарные входящие записи с курсором, раздельная доставка текста и медиа, контроль неопределённых отправок, сохранение random_id, безопасное скачивание, single-process lock, системный unit и локальные тесты.

Это пилотная версия. Реальная авторизация, серверная установка, SOCKS5, загрузка реальных вложений и полнота восстановления на конкретном аккаунте требуют проверки перед постоянным использованием. Данных, токенов или изменений telemax в релизе нет.
